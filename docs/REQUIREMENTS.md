# SoulPet 灵宠 · 需求规格（v1.0 草案）

> 原始需求：一个桌面电子宠物，**可以自定义形象**，有**养成系统**，**接入 AI API**，有**自己的记忆（AI 记忆库）**，以及其他暂时没想到的需求。
>
> 本文把这四句话展开成可落地、可验收的需求，并补上"没想到的部分"。优先级：**P0** = 本次 v0.1 必做；**P1** = 下一版；**P2** = 远期 / 可选。
> 标记 ✅ 的条目已在当前代码里实现。

---

## 0. 产品定位与设计原则

一只常驻桌面、"有灵魂"的电子宠物：长相可以换，需要你照顾，能用大模型和你聊天，并且**记得你们之间发生过的事**。

| 原则 | 含义 |
| --- | --- |
| 本地优先 | 所有存档、聊天记录、记忆库都存在本机；不做任何遥测。只有调用你配置的模型 API 时数据才会出网。 |
| 轻量常驻 | 空闲时几乎不占 CPU；宠物窗口很小、只在需要时重绘。 |
| 不打扰 | 有免打扰、安静时段、全屏自动隐藏；主动搭话有每日次数上限。 |
| 一切可换 | 形象包、人设卡、模型服务商、记忆检索方式都可以替换。 |
| 成本可控 | 每日 token 预算；没有 Embedding 也能用（退化为关键词检索）。 |
| 不会"死" | 养成是陪伴而不是惩罚：数值低了会生病、闹情绪，但不会永久死亡。 |

主平台 **Windows 10/11 x64**（便携版 zip + 安装包），兼顾 macOS / Linux。

## 2. 养成系统（Tamagotchi）

### 2.1 数值
| 数值 | 范围 | 变化规律 |
| --- | --- | --- |
| 饱食 satiety | 0–100 | 每小时下降；喂食恢复 |
| 心情 mood | 0–100 | 玩耍、抚摸、聊天提升；饥饿、脏、生病时持续下降 |
| 精力 energy | 0–100 | 清醒时下降，睡觉时恢复；打工/玩耍消耗 |
| 清洁 cleanliness | 0–100 | 缓慢下降；洗澡恢复 |
| 健康 health | 0–100 | 饱食或清洁过低时下降，状态好时缓慢自愈；< 30 进入"生病"状态 |
| 好感 affection | 0–1000 | 互动和聊天累积（有每日上限，防刷），决定亲密等级和称呼方式 |
| 经验 / 等级 | — | 各种互动给经验；等级决定成长阶段（幼年 1–4 / 少年 5–14 / 成年 15+） |
| 金币 coins | — | 打工、专注（番茄钟）、每日签到获得；用于商店 |

### 2.2 需求
| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| G1 | 上述数值 + 随时间自然变化（纯函数引擎，便于测试与平衡） | P0 ✅ |
| G2 | **离线结算**：关掉程序期间也会流逝，但有封顶（默认最多结算 12 小时）且有保底，回来不会面对一只"快饿死"的宠物 | P0 ✅ |
| G3 | 互动动作：喂食、洗澡、玩耍、抚摸、睡觉/起床、打工、学习、看病 | P0 ✅ |
| G4 | 物品与背包：食物 / 饮料 / 玩具 / 药品 / 清洁用品，有效果与价格 | P0 ✅ |
| G5 | 商店（金币购买） | P0 ✅ |
| G6 | 等级、成长阶段、升级奖励 | P0 ✅ |
| G7 | 难度：休闲 / 标准 / 硬核（调节衰减速度） | P0 ✅ |
| G8 | 每日签到、成就徽章 | P0 ✅ |
| G9 | 番茄钟/专注模式：宠物陪你"一起工作"，完成后得金币和经验 | P1 ✅ |
| G10 | 随机事件：捡到金币、做了个梦、心血来潮的小请求 | P1 ✅ |
| G11 | 数值会影响 AI：饿了会在聊天里撒娇要吃的，困了说话没精神 | P0 ✅ |
| G12 | 物品可由形象包 / MOD 扩展 | P2 |

## 4. 记忆库（Memory）

目标：宠物**记得你是谁、你喜欢什么、你们一起经历过什么**，而且你能看到、修改、删除它记住的东西。

### 4.1 记忆分层
| 层 | 内容 | 存储 |
| --- | --- | --- |
| 工作记忆 | 最近 N 轮对话，直接放进上下文 | `chat/YYYY-MM-DD.jsonl` |
| 长期记忆 | 关于你的事实、偏好、约定；宠物自己的设定与经历；重要事件 | `memory.json` |
| 情节摘要 | 过长的旧对话被压缩成摘要，作为一条记忆 | 同上（type=episode） |
| 反思 / 日记 | 宠物每天写一篇日记，提炼出更高层的认识 | `diary.json` + 记忆（type=reflection） |

### 4.2 需求
| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| M1 | 记忆条目结构：内容、类型、重要度（1–10）、创建/更新/最近访问时间、访问次数、来源、是否置顶、向量（可选） | P0 ✅ |
| M2 | **自动抽取**：每轮对话后由模型判断是否要 新增 / 更新 / 删除 记忆（参考 mem0 的 ADD/UPDATE/DELETE），避免重复和矛盾 | P0 ✅ |
| M3 | 用户说"记住……"时强制写入并提高重要度；说"忘掉……"时删除 | P0 ✅ |
| M4 | **混合检索**：关键词 BM25（中英文都支持）+ 向量相似度（配置了 Embedding 时）+ 时间新近度 + 重要度加权（参考 Generative Agents） | P0 ✅ |
| M5 | 没有 Embedding 服务（如只用 DeepSeek）时自动退化为纯关键词检索，功能可用 | P0 ✅ |
| M6 | 置顶的"核心记忆"（如你的名字、生日）始终放进上下文 | P0 ✅ |
| M7 | 记忆管理界面：搜索、编辑、删除、置顶、手动添加 | P0 ✅ |
| M8 | 导出 / 导入（JSON），换电脑不丢 | P0 ✅ |
| M9 | 每日日记 + 反思（定时或手动触发） | P0 ✅（手动/每日首次启动） |
| M10 | 遗忘曲线：长期不被想起的低重要度记忆检索权重下降 | P0 ✅（检索时衰减） |
| M11 | 对话压缩：历史超过阈值时自动摘要 | P1 ✅（每日情节摘要） |
| M12 | 记忆整理（"做梦"）：合并相似记忆、清理过期内容 | P1 ✅ |
| M13 | 本地 Embedding 模型（transformers.js / Ollama），完全离线 | P2 |
| M14 | 记忆加密存储、多设备同步 | P2 |

## 6. 非功能需求

| 项 | 指标 |
| --- | --- |
| 资源占用 | 空闲时 CPU < 1%；宠物窗口按需渲染，失焦时降低帧率 |
| 启动 | 冷启动 < 3 s 出现宠物 |
| 数据安全 | 所有写入采用"临时文件 + 原子重命名"，断电不损坏存档；API Key 加密 |
| 隐私 | 无遥测；日志不记录 Key；发送给模型的内容可在设置中查看（调试模式） |
| 可测试 | 养成引擎、记忆检索、提示词构建、协议解析都是纯 TypeScript，可单元测试 |
| 可移植 | 存档格式有版本号，支持迁移 |

## 7. 版本规划

- **v0.1**：上面所有 P0 —— 能在桌面上跑、能换形象、能养、能聊、能记住你。
- **v0.2（已完成）**：首次启动引导、提醒/待办/番茄钟、让 AI 设提醒、记忆整理与情节摘要、成就、随机事件、语音朗读、鼠标穿透、zip 导入形象包、代理设置、日志文件。
- **v0.2.x**：全屏时自动隐藏、自动更新、语音输入。
- **v0.3**：语音（I12）、Live2D（A9）、本地 Embedding（M13）、多宠物（X13）、MOD（X14）。

## 8. v0.1 验收清单

1. 启动后屏幕底部出现默认宠物，会闲逛、能拖拽、松手会落下。
2. 把一个 Codex 格式的宠物文件夹放进 `pets/`，在面板中能切换过去并正常播放动画。
3. 数值随时间下降；关闭程序 3 小时后重开，数值按规则结算且不低于保底值。
4. 喂食/洗澡/玩耍/睡觉/打工都会改变对应数值，商店能用金币买东西。
5. 填入 DeepSeek（或任意 OpenAI 兼容）Key 后能流式聊天，宠物表情随情绪标签变化。
6. 告诉它"记住我喜欢吃草莓"，重启后问"我喜欢吃什么"，它能答出来；记忆面板里能看到并删除这条。
7. 不配置 Embedding 时记忆检索仍然有效。
8. 安静时段内不会主动说话；免打扰开启时不弹气泡。
