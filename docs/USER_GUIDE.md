# SoulPet 灵宠 使用说明

## 安装

**Windows**：下载 `SoulPet-x.y.z-win-x64.exe` 双击安装，或下载 `.zip` 解压后运行 `SoulPet.exe`。

- 想要“便携版”（数据跟着程序走，方便放进 U 盘）：在 `SoulPet.exe` 旁边新建一个名为 `SoulPetData` 的文件夹。
- 安装包没有代码签名，Windows 可能提示“已保护你的电脑”，点 **更多信息 → 仍要运行**。

**macOS**：下载 `.dmg`。第一次打开如果提示“无法验证开发者”，在“系统设置 → 隐私与安全性”里点“仍要打开”。
**Linux**：下载 `.AppImage`，`chmod +x` 后运行。

## 第一次使用

启动后会弹出引导，三步：

1. **起名字**：给它起名，告诉它怎么称呼你。
2. **接上大脑**：选一个大模型服务商，粘贴 API Key，点“保存并测试”。不想现在弄可以跳过，先只玩养成。
3. **选形象**：内置的“团子”可以换颜色。

## 和它互动

| 操作 | 效果 |
| --- | --- |
| 单击 | 摸摸它（加好感，连续猛戳会被嫌弃） |
| 双击 / `Ctrl+Alt+P` | 打开聊天框 |
| 拖动 | 放在哪儿就停在哪儿，屏幕顶部也行（这时气泡会出现在它下面）；用力甩会滑一段再停下。想让它松手就掉到屏幕底部，在 形象 → 重力 里打开 |
| 右键 | 弹出小菜单：左边 🎤 说话（按住说、松开发送；或者点一下开始、再点 ■ 发送），右边 ⌨ 打字 |
| 鼠标停在它身上 | 看它的状态 |
| `Ctrl+Alt+H` | 一键藏起来 / 叫出来 |
| 托盘图标 | 显示/隐藏、聊天、🐾 照顾它（喂食、洗澡、玩耍、睡觉、打工、学习、签到、专注）、面板、设置、免打扰、鼠标穿透、退出 |

### 聊天时可以这样说

- “**记住**我的生日是 3 月 5 日”：马上记进记忆库，并且设为重要
- “我喜欢吃什么？”“上周我们聊了什么？”：它会从记忆里找答案
- “**20 分钟后提醒我**喝水”“**每天 8 点**叫我吃早饭”“帮我**记一下**周五交报告”：设提醒和待办
- “**忘掉**我养猫这件事”：它会删除相关记忆

## 养成小贴士

- 五项数值：**饱食、心情、精力、清洁、健康**。饱食或清洁太低会掉健康，健康低于 30 会生病（要吃药）。
- 金币来源：**打工**（20 分钟冷却）、**签到**（连续签到奖励更多）、**升级奖励**、**专注番茄钟**、成就、偶尔捡到。
- 关掉程序后数值也会变化，但更温和，最多只算 12 小时，而且有保底，不会回来就看到奄奄一息的它。
- 宠物**不会死**。
- 嫌掉得太快？设置 → 养成 & 费用 → 难度选“休闲”。

## 选哪个模型？要花多少钱？

| 服务商 | 特点 |
| --- | --- |
| DeepSeek（默认） | 中文好、便宜，日常聊天每天通常只要几分钱 |
| 智谱 GLM（glm-4-flash） | 有免费模型 |
| 硅基流动 | 有免费的向量（记忆检索）和语音识别模型 |
| Claude / OpenAI | 理解力强，价格较高，国内可能需要代理 |
| Ollama | 完全本地、免费，需要电脑配置较好 |

每轮聊天大约是 **1 次聊天调用 + 1 次后台记忆整理调用**。可以在设置里：

- 给“记忆 / 日记用的模型”单独选一个便宜的模型；
- 设置“每日 token 上限”；
- 关掉“自动记住重要的事”（只记你明确说“记住”的事）。

## 记忆是怎么工作的？

- 每轮对话后，它会判断有没有值得记的事（新增 / 更新 / 删除），自动去重。
- 聊天时，它会挑出和当前话题最相关的几条记忆带给模型。“置顶”的记忆每次都会带上，适合放名字、生日这类重要信息。
- 每天会写日记，并总结前一天聊了什么；定期“做梦”整理，合并重复的记忆。
- 在 **面板 → 记忆** 里可以搜索、编辑、置顶、删除，也可以导出备份。
- 想按“意思”搜索记忆（而不只是关键词）：设置 → 记忆 → 打开“向量记忆”，用硅基流动的 bge-m3（免费）。

## 换形象

- **面板 → 形象**：切换内置形象，或者点“导入 .zip / 导入文件夹”。
- 支持 Codex Pet 格式：[Petdex](https://github.com/crafter-station/petdex) 上的宠物下载后直接导入。
- 想自己做：见 [形象包格式](PET_PACK.md)。用 AI 生成视频或序列帧都可以。

## 常见问题

**它不说话 / 回复“还没有接上大脑”**
→ 设置 → AI 模型，确认填了 API Key 并且“测试连接”成功。

**提示“API Key 无效”“余额不足”“连接失败”**
→ 检查 Key 是否复制完整、账户是否有余额。连接失败通常是网络问题：访问 OpenAI / Claude 一般需要代理，在 设置 → 通用 → 网络代理 填 `http://127.0.0.1:端口`。

**它挡住了我要点的东西**
→ 拖到别处；或者在托盘打开“鼠标穿透”；或者按 `Ctrl+Alt+H` 暂时藏起来。

**看视频时它还在**
→ Windows 上默认全屏时会自动隐藏（设置 → 通用 → 全屏时自动躲起来）。浏览器里的“网页全屏”不算真全屏，需要按 F11 或视频的全屏按钮。

**快捷键没反应**
→ 可能被别的软件占用了，在 设置 → 通用 里换一个。

**数据在哪？怎么备份 / 换电脑？**
→ 设置 → 通用 → 数据目录 → 打开。把整个文件夹复制走就是完整备份（API Key 是加密保存的，换电脑后需要重新填）。只想迁移记忆：记忆页面 → 导出 / 导入。

**出了问题怎么反馈？**
→ 设置 → 关于 → 诊断信息；设置 → 通用 → 查看日志。日志里不会出现你的 API Key。

## 隐私

- 所有存档、聊天记录、记忆都只保存在你的电脑上，没有任何统计上报。
- 只有在调用你配置的模型服务时，对话内容才会发给那个服务商。
- API Key 用系统钥匙串加密保存（Windows 下是 DPAPI）。
- 开启“检查更新”时，只会访问 GitHub 的 Releases 接口。开启“天气”时，只会把你填的城市名发给天气服务。
