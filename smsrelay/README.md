# 短信安全转发（SMS Relay）

把一台安卓手机收到的短信（验证码、银行通知等），**安全地**自动转发到你的其他手机。

- 安装包：[`release/SmsRelay-1.1.0.apk`](release/SmsRelay-1.1.0.apk)（约 110 KB，支持 Android 8.0 及以上）。可以直接覆盖安装旧版，设置和配对码会保留。
- 完全自己编写，**没有任何第三方代码库**，没有广告、没有统计、不联系开发者服务器。

---

## 一、安装

1. 把 `SmsRelay-1.1.0.apk` 传到手机上（数据线、网盘下载、或直接用手机浏览器打开本页面下载）。
2. 点开安装。如果提示“禁止安装未知来源应用”，按提示允许一次即可。
3. 打开“短信安全转发”。

> 安卓 13 及以上授权短信权限时，如果提示 **“受限设置”**：打开 系统设置 → 应用 → 短信安全转发 → 右上角 ⋮ → **允许受限制的设置**，再回到应用重新授权。

## 二、使用方法

应用底部有四页：**首页 / 发送 / 接收 / 说明**。

### 最推荐：另一台也是安卓手机（端到端加密）

| 收短信的手机（有 SIM 卡） | 另一台手机 |
|---|---|
| 1. 安装本应用，首页点“去授权”允许短信权限 | 1. 安装本应用 |
| 2. 「发送」页 → 开启 **加密推送到另一台安卓手机**，会显示 24 位配对码 | 2. 「接收」页 → 输入这个配对码 → 打开 **开始接收** |
| 3. 点 **发送测试消息** | 3. 几秒内弹出通知，有“复制验证码”按钮 |

同一个配对码可以输入到多台接收手机上。

### 远程发短信（v1.1 新增）

在另一台安卓手机上，让有 SIM 卡的那台手机替你发短信：

1. 有 SIM 卡的手机：「发送」页 → 加密推送 → 打开 **允许接收端远程发短信**（默认关闭）。
2. 另一台手机：「接收」页 → **远程发短信** → 填号码、内容，可选用卡1/卡2 → 发送。
3. 几秒后显示“✅ 已由发送端发出”（这是运营商网络确认后的真实结果）。

安全措施：指令端到端加密并校验（独立的通道和密钥），没有配对码无法伪造；超过 10 分钟的指令自动作废；同一条指令绝不执行两次；每小时最多 20 条；有 SIM 卡的手机每发一条都会弹出通知。

### 另一台是 iPhone

- **推送到 iPhone（Bark）**——推荐：在 App Store 安装免费开源的 *Bark*，把 Bark 首页的推送地址填进本应用，开启“端到端加密”，再把本应用显示的密钥填到 Bark 的“推送加密”设置里（算法 AES256、模式 CBC、Padding pkcs7）。
- **发送到邮箱**：iPhone 自带邮件即可接收。QQ / 163 / 126 邮箱需要使用“授权码”，Gmail / iCloud 需要“应用专用密码”，应用里有获取方法。

### 其他方式

| 方式 | 安全级别 | 说明 |
|---|---|---|
| 加密推送（安卓↔安卓） | 🟢 端到端加密 | 中转服务器只看到乱码 |
| Bark（开启加密） | 🟢 端到端加密 | 适合 iPhone |
| 邮件 | 🟡 传输加密 | 邮箱服务商能看到内容 |
| 企业微信 / 钉钉 / 飞书群机器人 | 🟡 传输加密 | 平台能看到内容 |
| Telegram 机器人 | 🟡 传输加密 | 中国大陆网络无法直接使用 |
| 短信转发到另一个号码 | 🔴 不加密 | 不需要网络，但要短信费，运营商能看到内容 |

可以同时开启多种方式；还可以设置“只转发包含关键词的短信”或“不转发某些号码/关键词”。

## 三、让转发更稳定（国产手机必看）

在**发送端和接收端**都设置：

1. 首页“不受省电策略限制”→ 去设置 → 允许。
2. 首页打开“后台常驻”。
3. 系统设置 → 应用 → 短信安全转发 → 开启 **自启动 / 允许后台活动**，电池选 **无限制**。
4. **小米 / 红米**：应用权限里把 **通知类短信** 设为允许（否则收不到验证码短信）。
5. 在最近任务里给应用“加锁”。

## 四、安全设计

- **端到端加密**：AES-256-GCM（每条消息独立随机数，带完整性校验），密钥由配对码经 HKDF-SHA256 派生。中转服务器（默认开源的 [ntfy.sh](https://ntfy.sh)，可换成自建服务器）无法读取、篡改或伪造消息。
- **配对码**：系统安全随机数生成，115 位强度 + 1 位校验（输错会立即提示），只存在你的手机上。
- **只走加密连接**：所有网络请求强制 HTTPS / TLS 1.2+，校验证书和域名；系统层面禁止明文流量，且不信任用户自行安装的证书（防中间人）。
- **本地加密存储**：邮箱授权码、令牌、配对码等用 Android Keystore（多数手机有硬件保护、密钥不可导出）加密后保存。
- **防泄露**：关闭系统备份和设备迁移导出；界面禁止截屏/录屏；输入框禁止自动填充和键盘学习；锁屏通知只显示“收到一条转发短信”；发布版本移除所有日志输出。
- **防伪造**：只有系统电话模块能把短信交给本应用（`BROADCAST_SMS` 权限保护）。
- **防循环**：短信通道每小时最多 30 条，并忽略对方转发回来的短信。
- **远程发短信**：默认关闭；指令走独立的加密通道，带时间戳和唯一编号，过期或重复的指令一律拒绝；每小时最多 20 条；每次执行都通知手机主人。
- **零第三方依赖**：应用只使用安卓系统自带功能和 Kotlin 标准库，所有代码都在本目录中，可以自行审查。

## 五、可靠性

- 收到的短信先写入本地队列再发送；网络不好时自动重试（约一天内重试 10 次，重启手机后继续）。
- 接收端断网后重连，会自动补收离线期间的消息（中转服务器保留约 12 小时）。
- 首页能看到每条短信在每个通道的发送结果，失败会有通知提醒，可以一键重试。

## 技术说明（给懂技术的朋友）

```
smsrelay/
  app/src/main/java/com/smsrelay/secure/
    core/      纯 Kotlin，无安卓依赖，可单元测试
      Pairing.kt   配对码（Crockford Base32 + 校验位）
      E2E.kt       HKDF-SHA256 + AES-256-GCM 信封，topic 作为 AAD
      Payload.kt   明文格式与长短信分片（每片 < 4096 字节）
      Ntfy.kt      ntfy 发布 / JSON 流订阅
      Smtp.kt      仅 TLS 的 SMTP 客户端（SSL 或强制 STARTTLS）
      Services.kt  Bark（AES-CBC）、Telegram、企业微信/钉钉/飞书
      Remote.kt    远程发短信指令/回执格式、时效与内容校验
      Http.kt      仅 HTTPS、不跟随重定向
    data/      Keystore 加密设置、SQLite 队列
    forward/   短信接收、发件队列、重试（JobScheduler）
    receive/   中转长连接（接收短信 / 接收远程指令）、解密、去重、分片重组
    remote/    远程发短信：发起端、执行端、运营商发送回执
    ui/        纯代码构建的界面（无 UI 库）
```
