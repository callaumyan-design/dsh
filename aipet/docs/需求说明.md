# AI 小桌宠 · 需求说明

## 一句话

一只住在安卓手机屏幕上的小家伙。**重点是交互和“活人感”**：它有身体、有脾气、有自己的作息，能感觉到你的手机在发生什么，每一下触碰都有回应。聊天只是可选的附加功能——聊天随便一个 AI App 都能做，桌宠的价值在于“它像活的”。

## v0.2 方向调整（按用户反馈）

> 用户原话：“重交互和活人感。重点不在于聊天，聊天随便一个 AI App 就可以用。”

所以 v0.2 的核心从“能聊天的悬浮窗”改成“像活的一样的小生命”：

| 维度 | 做了什么 | 为什么能带来活人感 |
|---|---|---|
| **身体** | 重力、拎起来、扔出去、旋转、弹跳、摔疼/摔晕、撞墙；轻轻扔到墙上会粘住并爬墙；果冻一样的弹簧身体，戳哪里哪里凹 | 有物理反馈 = 有“实体”，不是一张贴纸 |
| **触碰** | 头/脸/肚子/小芽四个部位反应不同；连戳会从不耐烦升级到真生气（冒烟、转身走开）；来回蹭是摸摸，能把它哄好；快速划过是推它 | 同一个动作做多了，它的反应会变——像有情绪 |
| **感知** | 锁屏久了回来先看到它在睡觉，再醒来打招呼（离开越久越激动）；充电时“吃电”；电量低会饿、没力气；摇手机会晕；斜着拿会往下滑；放音乐会跳舞；插耳机会好奇 | 它“知道”你和手机在干什么 |
| **内心** | 心情、精力、无聊、烦躁、亲密度随时间和你的对待变化；它据此决定做什么、用什么表情 | 行为有原因，而不是随机播放动画 |
| **自主生活** | 没人理时：东张西望、溜达、坐着发呆、伸懒腰、哼歌、自己蹦着玩、爬墙、做白日梦、晚上犯困睡觉；无聊久了跑出来找你；生气了背过身生闷气 | 你不看它的时候它也在“生活” |
| **记忆** | 认识第几天（每天第一次见面会提）、今天摸了几次/喂了几次/扔了几次；老扔它会记仇 | 关系会累积 |
| **照顾** | 菜单里喂零食：零食从天上掉下来，它接住吃掉；哄它睡觉 | 你能为它做点什么 |
| **表达** | 16 种表情、9 种姿势、各种小特效（爱心、音符、闪电、汗滴、青筋、金星、Zzz、问号叹号）；本地台词库按情境挑话、不重复 | 细节多，才不容易“穿帮” |

**全部本地运行，不需要 AI、不需要联网、不需要额外权限。**

### 交互设计取舍

- **点 = 戳，按住 = 拎起来，按住不动松开 = 菜单**。没有用“双击开菜单”，因为那样连戳几下就会误开菜单，“戳到它生气”就玩不成了。
- **默认有重力**：它大部分时间在屏幕底部和两侧墙上活动，溜达时偏向两边，尽量不挡屏幕中间的内容。不喜欢可以关掉重力，变成“放哪儿待哪儿”。
- **摇晃/倾斜/音乐感应都可以单独关**；锁屏时全部停止，省电。

### 以后可以加（等你玩过再决定）

- 感知你正在用的 App（比如刷短视频太久它会提醒）——需要“使用情况访问”权限，隐私敏感，所以没默认做
- 更多可以喂/玩的东西（球、毛线团）、换装、节日彩蛋
- 和电脑版 SoulPet 灵宠的形象/记忆打通
- 让 AI 根据它的状态生成更个性化的台词（现在是可选开关）

## v0.1 时的基础需求

## 给谁用

- 不懂技术的普通安卓手机用户。
- 安装方式：下载一个 APK 安装包直接装，不需要应用商店、不需要电脑。
- 唯一需要自己准备的：一个 AI 服务的 API Key（钥匙），App 里有申请入口和说明。

## 已确定的方案（以及为什么）

| 决定 | 理由 |
|---|---|
| 做原生安卓 App（不是网页） | 只有原生 App 才能“浮在其他 App 上面”，这是桌宠的核心体验 |
| 聊天窗口也做成悬浮窗 | 不会把你从正在用的 App 里拉走；小米/华为等手机不需要额外的“后台弹出界面”权限 |
| 桌宠形象用代码画（原创“团子”） | 不需要图片素材、放大不糊、动画流畅、可以换颜色和大小，也没有版权问题 |
| 支持多家 AI，可随时切换 | Claude 质量好但中国大陆连不上；DeepSeek/通义千问/智谱/Kimi 国内直连且便宜 |
| 所有数据只存在手机本地 | API Key、聊天记录不经过任何第三方服务器，只发给你选的 AI 服务 |
| 默认设置都偏省钱 | 主动搭话默认用本地台词，不花 AI 额度；需要时再打开“让 AI 想内容” |

## v0.1 功能清单

### 桌宠本体
- [x] 悬浮在所有 App 之上，可以拖到屏幕任意位置，位置会记住
- [x] 动作：呼吸、眨眼、东张西望、走路、睡觉（冒 Zzz）、开心（冒爱心）、思考（头顶小圆点）、说话（嘴巴一张一合）、被拎起来（> < 表情、脚晃来晃去）
- [x] 自己在屏幕上左右溜达（可关闭）
- [x] 一段时间没人理会犯困睡觉，深夜更容易困；点它会醒
- [x] 头顶对话气泡，点气泡打开聊天
- [x] 6 种颜色、60%–160% 大小可调
- [x] 屏幕关闭时停止动画，省电

### 互动
- [x] 点一下 → 打开聊天窗口
- [x] 长按 → 摸摸头（开心、冒爱心、说句话）
- [x] 拖动 → 换位置（偶尔会喊“放我下来”）

### AI 聊天
- [x] 悬浮聊天窗口，回复一个字一个字地出现，可以中途停止
- [x] 记住最近的聊天内容（最多保存 300 条，每次带最近 30 条给 AI）
- [x] 名字、性格可改，4 个性格预设（软萌黏人 / 傲娇猫系 / 元气学霸 / 安静陪伴）
- [x] “关于你的事”：写下想让它记住的信息
- [x] 偶尔主动搭话（约半小时一次，可关闭；可选让 AI 生成内容）
- [x] 把回复读出来（用手机自带的语音，可关闭）
- [x] 出错时用人话解释（钥匙不对、余额不足、网络不通……）
- [x] 一键清空聊天记忆

### AI 服务
- [x] Claude（Anthropic 官方 SDK，默认 claude-opus-5-5）
- [x] DeepSeek、通义千问、智谱 GLM、Kimi、硅基流动
- [x] 自定义任意 OpenAI 兼容接口（OpenAI、中转服务等）
- [x] “选模型”按钮自动拉取可用模型列表；“测试一下”按钮检查设置对不对

### 常驻与权限
- [x] 前台服务 + 通知栏常驻，通知里有“聊天 / 收起 / 退出”按钮
- [x] 开机后自动出现（可关闭）；App 更新后自动恢复
- [x] 设置页一步步引导开启权限：悬浮窗、通知、电池优化白名单

## 以后可以加（v0.2+，等你用过再决定）

- 自动记忆：让它自己从聊天里总结“关于主人的事”
- 语音输入：按住说话（很多国产手机没有谷歌语音服务，需要接其他语音识别）
- 更多形象/换装、节日彩蛋
- 提醒功能：喝水、休息、日程
- 看懂截图：把屏幕截图发给它问问题
- 桌面小组件

## 不做的事

- 不收集任何数据，没有账号系统、没有服务器
- 不上架应用商店（需要开发者账号和审核），用 APK 直接安装

## 验收标准

1. 安装后按设置页的 ①②③ 步骤开权限，点“让它出来”，桌宠出现在桌面上并能在任意 App 上方看到。
2. 拖动、点击、长按都有对应反应；放着不管它会溜达，过一阵会睡觉。
3. 填好 API Key 后点“测试一下”显示连接成功；点桌宠能正常聊天，回复逐字出现。
4. 锁屏再解锁、切换 App 后它还在；重启手机后自动出现（开关打开时）。
5. 通知栏可以收起/叫出来/退出。
